# Versed

A daily lyrics game: how many words of the song can you remember?

- **Daily**: one song a day for everyone, with a shareable score grid.
- **By artist / Any song**: unlimited play from LRCLIB's catalog.
- **Listen**: a 30-second Apple Music clip, or link a YouTube video to replay any line.

Static site, no build step. Lyrics are loaded at play time from [LRCLIB](https://lrclib.net); none are stored here.
Optional: add a YouTube Data API key in `config.js` so videos are found automatically.
